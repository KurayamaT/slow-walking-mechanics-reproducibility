# Code and data for perturbation recovery in slow walking

This repository contains the numerical code, derived data, and figures supporting the manuscript **“Toward the low-speed limit of walking: mechanics of perturbation recovery in an actively powered simplest walking model”**, prepared for submission to the *Journal of Biomechanical Science and Engineering* (JBSE).

The study uses a theoretical walking model. The repository contains no human participant data. The manuscript and its supplementary material describe the model, analysis, and the meaning of each figure and table.

`code_matlab/+wk/` contains the numerical walking map shared by the MATLAB analyses. `data_matlab/branches/` contains cached parameter-sweep branches. `code/`, `data_python/`, and `data/` contain the independent Python calculations and their outputs; `verify_matlab_port.py` compares the MATLAB and Python outputs. `legacy/results/csv/` holds the earlier foot-mass sweep inputs used by `code_matlab/run_beta_summary.m` and `code_matlab/run_beta_realised.m`. The original sweep scripts are retained in `legacy/code/`.

The TIFF files in `submitted_figures/` are the versions embedded in the JBSE manuscript. `figures_matlab/` contains numerical plotting outputs and reference panels, which are not necessarily identical in layout to the final TIFF files.

## Check the reported numbers

From the repository root, run:

```bash
python3 verify_matlab_port.py
```

This reads the stored CSV files without changing them. It compares the MATLAB and Python results and recomputes the numerical values quoted in the manuscript and supplement. Python 3 is sufficient for this check. In the stored branch, the maximum MATLAB–Python differences are `3.10e-07` in the dominant multiplier and `4.00e-04` steps in half-life.

For fresh computations, use MATLAB with the `code_matlab/` directory on the path. The main branch can be regenerated by `run_extend_family`; then the transition, nonlinear traces, scaling, and attribution can be regenerated by the scripts listed in the table. These full sweeps can take substantially longer than checking the stored results. Some optional analyses use MATLAB Parallel Computing Toolbox when available. Independent Python computations use the packages in `requirements.txt`; for example, `code/jacobian_decomposition_check.py` uses NumPy and SciPy.

## Provenance

The files were assembled from the study workspace for the JBSE submission. `SOURCE_COMMIT.txt` records the workspace commit used for the snapshot. The two public MATLAB copies that read historical foot-mass CSV files were adjusted only to point to this repository's `legacy/results/csv/` directory. The source workspace files were not changed by that path adjustment.
