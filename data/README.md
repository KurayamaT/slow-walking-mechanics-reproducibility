# Data files

This directory contains Python cross-check data and older outputs, including
MATLAB-generated summary files. The current MATLAB results used in the manuscript
and Supplementary material are in `../data_matlab/`, with scripts in
`../code_matlab/`. The foot-mass comparison in Figure S4c uses
`../data_matlab/a5_beta_realised.csv`, independently generated by
`../code_matlab/run_beta_realised.m`. The Python file in this directory is retained
only as the independent comparison reference.
`../verify_matlab_port.py` compares selected CSV files in `../data_python/` (if
present; otherwise this directory) with those in `../data_matlab/`.

All quantities are dimensionless unless stated. The branch parameter `q` sets the
push-off through $\alpha_p=\arcsin(q/2)$ and $P(q)=c\alpha_p\tan\alpha_p$.
The realised step length is $s=2\sin\alpha_h$, stored as `s` or `s_real` in current
files; `alpha_h` is the heel-strike half-angle, `T` is the step period, and
$v=s/T$. `lam_max` is the spectral radius $\rho$, `recovery_margin` is $1-\rho$,
and `N_half` is $-\ln 2/\ln\rho$ for stable gaits.

In the older `master_fixed_khip.csv` and `supp_validation*.csv` files, the column
named `s` stores `q`, and `v` was calculated as $q/T$. The `s` column in
`fig2b_traces.csv` also stores `q`. These values must not be read as realised step
lengths or speeds. The current `master_fixed_khip_extended.csv` has separate `q`
and realised `s` columns.

## The two solution methods

The files below contain earlier direct-Newton results and continuation results
for the fixed-`k_hip` branch (`k_hip = -0.16`).

| File | Method | Grid |
|---|---|---|
| `master_fixed_khip.csv` | direct Newton at each prescribed push-off | 1990 stored rows; the legacy `s` column denotes `q` |
| `master_fixed_khip_extended.csv` | seeded continuation, each solution seeding the next | 791 points at 0.001 spacing over `q ∈ [0.01, 0.80]`, reaching the slow end |

**The manuscript uses `../data_matlab/master_fixed_khip_extended.csv`.** Use that
file for the reported branch and realised geometry. The older direct-Newton file
is retained as a historical output and should not be substituted for it.

## Other files

| File | Contents |
|---|---|
| `supp_khip_sweep.csv` | hip-spring sweep, `k_hip` from -0.30 to +0.10 (nine branches), each over 791 `q` values from 0.010 to 0.800; `s` stores realised step length |
| `supp_csweep.csv` | push-off coefficient `c ∈ {0.8, 1.0, 1.04, 1.2}` in $P(q)=c\alpha_p\tan\alpha_p$, each over 791 `q` values from 0.010 to 0.800; `s` stores realised step length |

| `a5_beta_realised.csv` | Python reference for independent comparison of `β = 0, 0.05, 0.10, 0.15` over `q = 0.040–0.088`; Figure S4c now uses the independently reproduced MATLAB file in `../data_matlab/` |
| `lowspeed_scaling.csv` | log–log fits of `1-ρ = C·s^p` over nested ranges — Table S3, Figure 4 |
| `slowend_verification.csv`, `slowend_modal.csv`, `slowend_series.npz` | Python verification outputs from 5,000-step nonlinear iteration at `q = 0.010`; the current MATLAB time series are in `../data_matlab/slowend_series.mat` — Table S2, Figure S3 |
| `fig2b_traces.csv` | nonlinear recovery traces at `q = 0.080` and `q = 0.402` — Figure 2b |
| `supp_validation_delta.csv` | differencing step `δ` and ODE `rtol` sweeps — Table S1, Figure S1a |
| `supp_validation_branch.csv` | fixed-point residual, `lam3_abs`, and 2D-vs-3D Jacobian agreement along the branch — Figure S1b |
| `transition_spectrum.csv` | trace, determinant, discriminant and the complex pair near the transition — Figure S2 |
| `sens_amplitude.csv`, `amp_traces.csv` | perturbation-amplitude dependence |
| `master_transition.txt`, `phase0_SL_SF_transect_summary.csv`, `u7_phase1_grid_*.csv` | earlier exploratory sweeps, not cited in the manuscript |

Python scripts and older MATLAB scripts for files in this directory are in
`../code/`. Current MATLAB scripts write to `../data_matlab/`; the Supplementary
material's Data and code table lists the files used for each analysis.
